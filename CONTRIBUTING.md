# Contributing

KeepTaste is a **finished personal project**, published as a portfolio case
study. It is not actively developed, and **contributions are not accepted**:
pull requests and feature requests will be closed without review.

You are welcome to read, learn from and fork the code under the
[MIT license](LICENSE). The KeepTaste name, logo and store art are not part
of that license, so a fork needs its own
([TRADEMARKS.md](TRADEMARKS.md)). If you fork it, the
[architecture decision records](docs/adr/README.md) explain why the code
is built the way it is, and what was tried and rejected.

**Security issues** are the exception. Please report them privately, as
described in [SECURITY.md](SECURITY.md).
